# extantword.github.io

Mi página: una tarjeta por proyecto, con una vista previa del sitio y enlace al código.

**<https://extantword.github.io/>** · en inglés: **<https://extantword.github.io/?lang=en>**

La lista está en `index.html` (la constante `GROUPS`), con cada texto en español y en inglés; el botón
EN/ES cambia de idioma. Las vistas previas son capturas de cada sitio, en `previews/`. Al cargar, la
página consulta la API de GitHub para actualizar lenguajes, años y estrellas.
