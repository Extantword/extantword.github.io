# extantword.github.io

Mi página: una tarjeta por cada proyecto público, agrupadas por tema, con enlace al código y al sitio
cuando lo tiene.

**<https://extantword.github.io/>**

La lista está en `index.html` (la constante `GROUPS`). Al cargar, la página consulta la API de GitHub:
actualiza lenguajes, años y estrellas, y pone en "Nuevos" los repositorios públicos que aún no están
en la lista.
